# Phase-encode ladder, live Gpe value and TR jump: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the TR-to-TR phase-encode stepping visible in the k-space explorer: a 9-step ladder behind each phase-encode
lobe, the live Gpe amplitude under its label, and a slider to jump to any TR.

**Architecture:** The ladder and the static "of ±peak" scale line are opt-in drawing in `shared/seqdiagram.js`
(`opts.ladder`), so the contrast page is unchanged. The live value is a small SVG fragment from a new pure function in
the same file, drawn into the k-space page's cursor overlay, which is already redrawn every frame. Each single-slice
shot records its k-space rows (`kspace/scan.js`), which feed a pure read-out helper; `kspace/ui.js` wires a range input.

**Tech Stack:** Static ES modules, no build; `node --test`; headless-Chrome page checks in `tools/smoke.mjs`.

**Spec:** `docs/superpowers/specs/2026-11-10-pe-ladder-design.md`

## Global Constraints

- Display only: no change to physics, timing, k-space path or reconstruction.
- Ladder: 9 outlines at amplitudes `peak × j / 4`, j = −4…4, with the timing of the lobe they sit behind, for every
  gradient labelled `"phase encode"` or `"phase rewinder"`; never for `"phase prephaser"` or EPI blips.
  Peak = `opts.peaks?.y` when given, else this sequence's largest |y amplitude|.
- Contrast page (`contrast/`) output unchanged: with `opts.ladder` absent, `diagramSvg` returns exactly what it does today.
- Live value text: sign always shown, `+29.7 mT/m`, `−29.7 mT/m` (U+2212 minus), `0.0 mT/m` at zero; one decimal.
- Scale line (per-axis mode only, with `opts.ladder`): `of ±30.7` replacing the Gpe row's `30.7 mT/m` line.
- Read-outs: `TR 65 of 128 · line 64 (centre)` (SE/GRE; "(centre)" only at row ny/2); FSE `TR 3 of 16` plus
  ` · holds the centre line` when the shot contains row ny/2. Slider hidden when the scan has one TR.
- Run all tests with `node --test --test-concurrency=1 "**/*.test.js"` (the cross-talk timing tests are noisy in parallel).

## Review Focus

1. Dragging the TR slider at 256 × 256 (256 TRs) and with several slices: the page keeps up (no long stalls per input).
2. Jumping backwards (e.g. TR 100 → TR 3): the k-space grid and image drop the later lines, as ◀ TR would.
3. FSE playback: the live value changes at each echo's phase encode, and resets to the first echo's at a new TR.
4. Changing a setting that changes the number of TRs (matrix, ETL, sequence): slider max and value follow, no stale TR.
5. Shared-scale mode (`#scale` = "shared", "true relative strength"): ladder still drawn within the row, live value still shown, no "of ±" line.

Items 2, 4 and 5 are pinned by tests in Tasks 1 and 3; 1 and 3 are for the final reviewer to check by hand.

### Task 1: Ladder, scale line and live value in the diagram

**Files:**
- Modify: `shared/seqdiagram.js` (`diagramSvg` row labels and gradient drawing; new exports)
- Test: `shared/seqdiagram.test.js`

**Interfaces:**
- Produces: `diagramSvg(seq, { ...opts, ladder: true })`: ladder outlines as `<path class="pe-ladder" d="…" …>` (class first, then d) (fill none,
  stroke the Gpe colour, low opacity) drawn before the solid lobes; the Gpe peak line reads `of ±30.7` (per-axis mode).
- Produces: `phaseEncodeAt(seq, t) -> number | null`: amplitude (mT/m) of the latest `"phase encode"` gradient with
  `start <= t`; the first one when none has started; `null` when the sequence has none.
- Produces: `gpeValueSvg(seq, geom, t, fontScale = 1) -> string`: one `<text class="gpe-now" …>` under the Gpe label
  (x = `geom.left - 8`, text-anchor end, y = Gpe row middle + `fs * 1.35`, where Gpe is row index 2 and
  row middle = `geom.top + 2.5 * geom.rowH`), or `""` when `phaseEncodeAt` is null. With `opts.ladder` the static SVG
  draws no Gpe value line under the label; the `of ±` line sits above the label at row middle − `fs * 0.75`.

  from `shared/sequence.js`, P as in the existing tests)

```js
test("ladder: 9 outlines behind every phase encode and rewinder, none without opts.ladder or for EPI", () => {
  const se = spinEcho({ ...P, TE: 30, TR: 1000 }, 3);
  assert.equal((diagramSvg(se, { ladder: true }).match(/class="pe-ladder"/g) ?? []).length, 9);
  assert.equal(diagramSvg(se), diagramSvg(se, {})); // contrast page untouched
  assert.ok(!diagramSvg(se).includes("pe-ladder"));
  const fse = fastSpinEcho({ ...P, ETL: 4 }, [0, 1, 2, 3]); // a phase encode and a rewinder per echo
  assert.equal((diagramSvg(fse, { ladder: true }).match(/class="pe-ladder"/g) ?? []).length, 9 * 8);
  const e = epi({ ...P }, Array.from({ length: P.ny }, (_, i) => i));
  assert.ok(!diagramSvg(e, { ladder: true }).includes("pe-ladder"));
});

test("ladder spans the scan-wide peak: its top outline is as tall as a full-scale lobe", () => {
  const mid = spinEcho({ ...P, TE: 30, TR: 1000 }, P.ny / 2 - 1), peaks = { y: 20 };
  const ys = [...diagramSvg(mid, { ladder: true, peaks }).matchAll(/class="pe-ladder"[^>]*d="M[\d.]+,([\d.]+)L[\d.]+,([\d.]+)/g)]
    .map((m) => Number(m[2]) - Number(m[1]));
  const h = Math.max(...ys.map(Math.abs));
  assert.ok(Math.abs(Math.min(...ys) + Math.max(...ys)) < 0.5, "symmetric about the baseline");
  assert.ok(ys.some((y) => Math.abs(y) < 1e-6), "includes zero");
  assert.ok(h > 0);
});

test("with the ladder the Gpe label shows the scale as 'of ±peak'; without it, the old peak line", () => {
  const se = spinEcho({ ...P, TE: 30, TR: 1000 }, 0), peaks = { y: 30.65 };
  assert.ok(diagramSvg(se, { ladder: true, peaks }).includes(">of ±30.7<"));
  assert.ok(diagramSvg(se, { peaks }).includes(">30.7 mT/m<"));
  assert.ok(!diagramSvg(se, { ladder: true, peaks, scale: "shared" }).includes("of ±"));
});

test("phaseEncodeAt follows the latest phase encode to start, and gpeValueSvg formats it with its sign", () => {
  const fse = fastSpinEcho({ ...P, ETL: 4 }, [0, 10, P.ny / 2, P.ny - 1]);
  const pes = fse.events.filter((e) => e.label === "phase encode");
  assert.equal(phaseEncodeAt(fse, 0), pes[0].amp); // before any has started: the first
  assert.equal(phaseEncodeAt(fse, pes[2].start + 1e-6), pes[2].amp);
  assert.equal(phaseEncodeAt(fse, fse.tr), pes[3].amp);
  assert.equal(phaseEncodeAt(epi({ ...P }, [0, 1]), 1), null);
  const geom = diagramGeometry(fse, {});
  assert.match(gpeValueSvg(fse, geom, pes[2].start + 1e-6), />0\.0 mT\/m</);
  assert.match(gpeValueSvg(fse, geom, 0), new RegExp(`>${pes[0].amp >= 0 ? "\\+" : "−"}${Math.abs(pes[0].amp).toFixed(1)} mT/m<`));
  assert.equal(gpeValueSvg(epi({ ...P }, [0, 1]), geom, 1), "");
});
```

test("each shot records the rows it plays", () => {
  const s = buildShots("SE", { ...explorerParams(initialState("?seq=SE&matrix=32")) });
  assert.deepEqual(s.shots.map((x) => x.rows), Array.from({ length: 32 }, (_, i) => [i]));
  const f = buildShots("FSE", { ...explorerParams(initialState("?seq=FSE&matrix=32&etl=4")) });
  assert.deepEqual(f.shots.flatMap((x) => x.rows).sort((a, b) => a - b), Array.from({ length: 32 }, (_, i) => i));
  assert.deepEqual(f.full(1).rows, f.shots[1].rows);

test("TR read-out names the line, and flags the centre", () => {
