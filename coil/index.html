Coil geometry

d / R = 1 is a Helmholtz pair. Both coils carry equal currents in the same sense.

RF excitation uses this current as a signed peak cosine amplitude, not RMS. Positive current is counterclockwise viewed from the positive coil axis toward the coil. Negative current reverses the field.

Double the current: field strength doubles. Reverse it: arrows and the signed profile reverse. Double R at fixed I and N: center field halves. Select a pair and compare d/R = 0.5, 1, and 1.5; at d/R = 1 the second axial derivative vanishes at the midpoint.

The numerical solver sums 256 current elements per loop. N turns are treated as coincident loops. Near-wire fields are excluded because ideal filament fields diverge. Current is prescribed in amperes. The RF excitation tab interprets it as a peak sinusoidal amplitude.

Why the factor of two?
B⊥,peak = |Bpeak × B̂₀|
|B₁⁺| = B⊥,peak / 2
f₀ = (γ / 2π) B₀
α = γ |B₁⁺| τ
M∥ / M₀ = cos α    |M⊥| / M₀ = |sin α|

A linear RF oscillation decomposes into two equal, oppositely rotating components. The co-rotating component drives on-resonance excitation in the rotating-wave approximation. A negative current reverses RF phase by 180° but leaves these magnitude maps unchanged. This half-amplitude rule is specific to the real, linearly polarized field modeled here.

This is an ideal hard-pulse model: uniform B₀, on resonance, no relaxation, no gradients, no RF phase map, and no counter-rotating or longitudinal RF dynamics. Local transverse magnetization magnitude is not a reconstructed image or a receive-coil signal.
